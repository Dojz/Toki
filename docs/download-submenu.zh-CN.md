# 下载子菜单测试版

基于 Toki 1.0.4，版本号为 `1.0.4-download.1`。保留 Toki 的图标和设置页面。

## 使用

1. 在 Toki 中开启“强制无水印下载”，重新打开 TikTok。
2. 点击视频的分享／长按菜单里的普通“保存视频”入口。
3. 下载子菜单提供：
   - 普通下载：选择视频已有的无水印播放画质。
   - 原始画质：通过 TikWM 的原画任务接口解析，按返回文件直接下载。
   - 视频+字幕：保存 MP4，以及原语言和官方翻译两份 UTF-8 SRT。
   - 带字幕视频：选择原语言、官方翻译或双语，将字幕合成进 MP4 画面。

画质旁显示已经解析到的分辨率和文件大小。未获取到的信息不显示；带字幕视频合成前无法知道最终大小，因此不显示大小。源文件下载不重新编码；带字幕视频会重新编码为 H264。

视频保存到相册，遵循 Toki 的视频目录设置。两份 SRT 保存到 `Download/TikTok`，文件名中的 `original`／`translated` 和语言代码区分字幕，可以直接复制到电脑与视频一起使用。

官方字幕来自当前视频的完整字幕模型。先在 TikTok 中打开字幕及自动翻译。只有拿到原语言和译文两条完整轨道时，“视频+字幕”才会导出；缺少轨道会提示，不用原文冒充译文，不抓屏幕上的单句字幕，也不调用其他翻译服务。没有译文时仍可合成原语言字幕。

## 适配边界

- 基准是 Toki 当前支持的官方 TikTok 47.1.4；基础模块同时支持 47.0.3 和 46.8.3。
- 下载入口按 `download_method`、`single_song` 和 Aweme／Context 参数契约查找。只有唯一匹配时才接管下载按钮；不匹配或无法打开子菜单时继续调用 TikTok 原有下载。
- 新下载流程需要 Android 10 及以上；目标测试范围为 Android 11–16。
- 模块使用 libxposed API 102。NPatch 必须具备该 API 和 XposedService 支持。桌面编译与单元测试不能证明 NPatch／实机兼容性，仍须在设备上验证。
- Android 9 保留原有保存流程。
- 下载任务在 TikTok 进程内运行，可在进度窗口取消；强制停止 TikTok 会中断任务。

## 原始画质的含义

这里的“原始画质”沿用用户希望的选项名称，对应 TikWM 原画任务返回的媒体源。第三方返回的文件不等于可验证的上传者母版。无法取得原画任务地址时明确失败，不会用普通画质静默替换。

解析只发送该视频的公开分享地址，不发送 TikTok 登录 cookie、账号令牌或字幕。字幕始终从视频提供的官方轨道下载。没有把 tiktokkk 的 CC BY-NC 源码复制到 MIT 项目中。

## 实机验收

1. Android 11 与 16、TikTok 47.1.4、NPatch API 102：模块设置同步、登录、刷视频、打开保存子菜单。
2. 横屏与竖屏视频：检查菜单中的分辨率与下载文件一致；服务器不支持探测时对应信息隐藏。
3. 原画解析失败：显示失败；成功时与同一视频普通下载比较实际尺寸、大小及音画同步。
4. 打开官方中文字幕翻译：导出的原文和中文 SRT 都有完整时间轴，语言与播放界面一致。
5. 原文／译文／双语烧录：检查开头、中间、末尾和字幕间隙，没有上一句残留；字幕可直接在相册播放。
6. 取消、网络中断、缓存空间不足：没有发布半截 MP4／SRT；自定义视频目录不影响字幕目录。
7. 未启用增强或图集：保留原下载行为。

测试版签名与官方 Toki 不同。已有官方模块时，先导出配置，再卸载旧模块安装测试版；不要直接覆盖安装。此文档不代表已完成实机验收。
